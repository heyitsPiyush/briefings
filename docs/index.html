In related news, Asus has released urgent firmware updates for its routers to address multiple high-severity vulnerabilities, including CVE-2026-75775, CVE-2026-75779, and CVE-2026-93489, which could grant administrative access without a password, some exploitable by unauthenticated attackers on an adjacent network.
