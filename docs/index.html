As of August 9, 2026, exploit development news highlights several critical vulnerabilities and new techniques. A public proof-of-concept (PoC) has been released for CVE-2026-39875, a macOS vulnerability in the Common UNIX Printing System (CUPS) affecting Sonoma, Sequoia, and Tahoe versions, which allows an unprivileged local user to gain root privileges through arbitrary file writes by chaining two logic flaws in the cupsd daemon. Additionally, CVE-2026-64531, dubbed OVSwrap, is a 13-year-old Linux kernel memory corruption flaw in the Open vSwitch datapath enabling local privilege escalation to root, with a public exploit available for approximately 800 kernel builds. This vulnerability exploits a wraparound to achieve a kernel pointer leak, arbitrary kernel read, and a targeted decrement to ultimately zero out fsuid and fsgid.

Another significant development is the disclosure of CVE-2026-64564, or SCTPhantom, a nearly 18-year-old Linux kernel use-after-free vulnerability in the SCTP Dynamic Address Reconfiguration feature. This flaw permits unprivileged local users to escalate to full root and escape containers, with researchers demonstrating an exploit chain that uses a packet socket ring buffer to leak kernel memory, bypass KASLR, and build fake kernel objects for privilege escalation. Furthermore, new NatJack attacks, presented at Black Hat USA 2026, detail techniques to hijack TCP sessions and spoof DNS by manipulating NAT tables, affecting Windows NAT (CVE-2026-56181) and Linux Netfilter conntrack (CVE-2026-63913), requiring privileged access behind the same NAT as the victim. The L3akCTF 2026 writeups also showcased a React2Shell (CVE-2025-55182) RCE against Next.js 16, leveraging a UTF-16LE charset filter bypass.
