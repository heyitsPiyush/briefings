Exploit Development

deep

As of November 3, 2026, a critical remote code execution (RCE) vulnerability, CVE-2026-98432, affecting the Linux kernel's IPv4 TCP connection handling has been a major point of discussion. This use-after-free (UAF) flaw, present in kernel versions 4.4 and later, received a CVSS 3.1 score of 9.8. Researchers at Anthropic demonstrated a zero-click exploit for this vulnerability, which allows an unauthenticated remote attacker to gain root access on Linux servers with a Multipath TCP (MPTCP) listener, leveraging memory corruption to bypass KASLR and overwrite a callback pointer. While Anthropic has not publicly released their exploit, patched kernels are available, and the Go Security Team noted that Go versions 1.24 and later enable MPTCP by default, expanding the potential attack surface. Additionally, SUSE Linux Kernel has multiple vulnerabilities, including those that could lead to remote code execution.

Other significant exploit news includes a publicly available proof-of-concept (PoC) for CVE-2023-21768, a Windows WinSock Ancillary privilege escalation vulnerability affecting Windows 11 22H2, which allows local attackers to gain SYSTEM privileges by writing to kernel memory. October also saw two critical PHP vulnerabilities, CVE-2026-109618 (out-of-memory handling) and CVE-2026-109619 (use-after-free), both with CVSSv4 scores of 9.2, that allow for unauthenticated remote code execution and have confirmed in-the-wild exploitation. Furthermore, a critical Brotli vulnerability, CVE-2026-111497, also rated 9.2, has a public PoC that can lead to unauthenticated remote code execution through memory corruption if a vulnerable network-facing process decodes a specially crafted Brotli stream. A critical Node-RED vulnerability, CVE-2026-58115, with a CVSS score of 10.0, is being actively exploited to install Linux malware and backdoors due to a lack of authentication on its management interface.
