Hardware Hacking

deep

Recent hardware hacking and embedded security news highlights several critical vulnerabilities and evolving attack methodologies. A significant firmware flaw in Coldcard hardware wallets, specifically impacting models with a March 2021 firmware build, led to the drainage of approximately 1,367 BTC, valued at around $89 million, from thousands of addresses since late July 2026. The vulnerability stemmed from weak random-number generation, routing seed generation to a deterministic software pseudorandom number generator instead of the more secure STM32 hardware random number generator, allowing attackers to reconstruct wallet seed phrases remotely. Additionally, Zbtlink router firmware has been found to ship with an embedded remote-control implant, ENDLESSDOORS, in every published build, operating with root privileges and phoning home over cleartext TCP, creating an unauthenticated remote code execution vulnerability. Furthermore, Acrisure KARR BT and DR-100 anti-theft systems are vulnerable to unauthorized vehicle control operations due to a shared Bluetooth authentication key across devices, addressed by a firmware update on July 20, 2026.

The landscape of side-channel and fault injection attacks continues to evolve, with increasing focus on firmware-based mitigations and advanced simulation tools. In 2026, researchers emphasize that addressing physical side-channel attacks like Simple Power Analysis (SPA), Differential Power Analysis (DPA), and Correlation Power Analysis (CPA) on microcontrollers now mandatorily involves software and low-level firmware updates, rather than solely hardware redesign, for legacy and cost-constrained devices in critical infrastructure and IoT. A new framework, InjectV, built on the gem5 simulator, has been introduced to model fault injection attacks in RISC-V environments, enabling precise and guided fault injection at security-critical execution points to assess resilience. Separately, a new side-channel attack named FROST (fingerprinting remotely using OPFS-based SSD timing) targets solid-state drives (SSDs) by measuring tiny delays in SSD activity through a browser's origin private file system, allowing inference of other computer activity. New publications also explore microarchitectural side-channel attacks on Intel mesh interconnects, demonstrating how an attacker can build a cross-core covert channel.
