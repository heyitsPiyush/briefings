October 2026 has seen significant activity in hardware hacking and embedded security, with a critical memory-corruption vulnerability (CVE-2026-97631) identified in TianoCore EDK II. This widely used open-source UEFI firmware codebase, affecting the PXE-Base Code driver, harbors a 16-year-old buffer overflow flaw in its ICMP component. The vulnerability allows attackers to execute malicious code during the boot sequence, bypassing security measures like Secure Boot, and potentially gaining privileged access at the CPU ring 0 level on most server vendors and data centers. Exploitation requires local network access and specially crafted error messages during a network boot. Dell also patched CVE-2026-86360, a critical path-traversal flaw in Dell System Update, allowing unauthenticated remote code execution with root privileges.

Supply chain attacks continue to pose significant risks, as exemplified by the Keystone hardware wallet incident where an attacker obtained a device verification key through a third-party data monitoring tool. This allowed for the potential creation of counterfeit devices, prompting Keystone to destroy nearly 19,000 unsold units. Additionally, a suspected hardware implant was found in Ledger devices sold through a Southeast Asian reseller, CryptoBilis, designed to steal 24-word recovery phrases during setup.
