October 2026 has seen a flurry of significant exploit developments, notably the widespread attention on the PHP2Shell vulnerabilities, CVE-2026-109618 and CVE-2026-109619. These critical memory corruption flaws, affecting PHP installations back to 2004, allow for unauthenticated remote code execution with a CVSSv4 score of 9.2. Public proof-of-concept (PoC) exploits rapidly emerged following their disclosure on October 21, 2026, and active exploitation has been confirmed, leading to their inclusion in the CISA Known Exploited Vulnerabilities catalog. Attackers have chained these PHP vulnerabilities with a Linux kernel local privilege escalation bug, CVE-2026-46300 (Fragnesia), to compromise internet-exposed Palo Alto Networks management interfaces and root servers across various regions.

Further exploit research and disclosures include Anthropic's Claude AI model developing five exploit chains, such as a one-click remote code execution in Chrome via V8 heap memory corruption and a race condition in CacheStorage, along with a zero-click root exploit for Linux servers (CVE-2026-98432) leveraging a use-after-free bug in the kernel networking stack. ZDI also published several advisories, including a remote code execution vulnerability in Telegram's rlottie library (0-day) due to a numeric truncation leading to a write before the start of an allocated buffer, and a local privilege escalation in the Linux kernel networking stack (ZDI-CAN-33367) allowing unprivileged users to alter in-memory file contents. Microsoft's October Patch Tuesday addressed over 1,400 vulnerabilities, with an actively exploited zero-day in Windows Shell (CVE-2026-96951) bypassing Mark of the Web defenses and a publicly disclosed .NET Framework security feature bypass (CVE-2026-108398).
