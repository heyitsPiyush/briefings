Exploit Development

deep

As of September 7, 2026, several significant exploit developments have emerged. Google addressed CVE-2026-85046, a high-severity type confusion vulnerability in Chrome's V8 JavaScript and WebAssembly engine, which was actively exploited in the wild and allowed for arbitrary code execution within the sandbox via crafted HTML pages. This marks the sixth Chrome zero-day patched this year, highlighting a consistent attack focus on V8. Additionally, unauthenticated remote code execution (RCE) vulnerabilities, CVE-2026-83548 (SSRF) and CVE-2026-83549 (OS command injection), were actively exploited in SonicWall SMA1000 appliances, with public proof-of-concept (PoC) code released to achieve RCE without authentication. Microsoft also disclosed multiple critical vulnerabilities, including CVE-2026-83711 and CVE-2026-70352, both rated CVSS 10.0, which are authorization bypasses in Azure AD B2C and Azure AI Language Authoring respectively.

Further exploit news includes a critical authentication bypass in end-of-life Proxmox VE 7.x releases (PSA-2026-00043-1), allowing unauthenticated root logins due to a flaw in the API login call's handling of tfa-challenge parameters. A privilege escalation zero-day, dubbed FalconFlank, was publicly disclosed in CrowdStrike Falcon Sensor for Windows, abusing the Office malicious macros remediation feature to achieve SYSTEM privileges on Windows 11 25H2 and Windows Server 2026. In memory corruption research, a "Download More RAM" attack, assigned CVE-2026-23670, demonstrated that some consumer memory modules lack write protection on configuration chips, enabling attackers to bypass Windows security like VBS and HVCI without physical access. Recent CTF writeups, such as those from ASIS CTF Quals 2026 and z0d1akCTF 2026 Qualifiers, also explored various cryptographic and web exploitation challenges. Project Zero and ZDI have continued to publish advisories, with ZDI detailing memory corruption and local privilege escalation vulnerabilities in pdfforge PDF Architect (ZDI-26-613, ZDI-26-615).
