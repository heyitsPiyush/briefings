Exploit Development

deep

Exploit development news for October 2026 highlights a significant number of vulnerabilities, particularly from Microsoft's Patch Tuesday, which disclosed 1,413 CVEs, including two zero-day bugs. One actively exploited zero-day, CVE-2026-96951, affects Windows Shell and allows a security feature bypass, specifically evading the Mark of the Web (MOTW) defense. This vulnerability, discovered by Anthropic's Claude AI, enables attackers to deliver specially crafted files via email or instant message to bypass security warnings. Another critical vulnerability, CVE-2026-105016, is a heap-based buffer overflow in Microsoft QUIC with a CVSS score of 9.8, allowing unauthenticated remote code execution.

Beyond Microsoft, Ivanti Connect Secure VPN appliances were targeted by a zero-day exploit chain, CVE-2026-104935, which combines an authentication bypass, remote code execution, and privilege escalation to achieve unauthenticated root-level code execution on fully patched systems up to version 22.8R2.4. Additionally, a critical authentication and authorization bypass in Fortinet FortiClient EMS, CVE-2026-35616, has a public proof-of-concept (PoC) and has been exploited in the wild, impacting versions 7.4.5 and 7.4.6. Another notable event was the public release of a WebKit browser vulnerability combined with a kernel-level aiomultiwait UAF race condition, dubbed "Relapse," affecting PlayStation 5 firmware versions 7.00 to 13.60, granting kernel-level physical memory read/write privileges. In September, China-linked threat actors chained a Google Chrome zero-day, CVE-2026-85046 (a V8 JavaScript engine type-confusion issue), with a Windows kernel privilege-escalation flaw, CVE-2026-85880, to deploy espionage payloads.
