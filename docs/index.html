Hardware Hacking

deep

Recent reports highlight critical firmware vulnerabilities and evolving side-channel attacks impacting various hardware. A significant 16-year-old flaw, CVE-2026-97631, exists in EDK II, the open-source code underpinning most UEFI firmware from vendors like AMI, Insyde, and Phoenix, as well as Microsoft's Project Mu. This buffer overflow in EDK II's PXE network boot code allows remote code execution during network boot, before the operating system loads, by crafting ICMP error messages that overwrite memory. Another recent finding, CVE-2026-120241, impacts Ruijie RG-ES205GC, RG-ES206GC-P, RG-ES208GC, RG-ES210GC-LP, and RG-ES210GS-P ESW_1.0(1)B1P48 series, involving a buffer overflow in the httpupg.cgi component of the local firmware upgrade interface, which is remotely exploitable. Furthermore, StealthCores has introduced StealthPQ, a post-quantum cryptography IP core designed to mitigate glitch and side-channel attacks by employing a dual-lockstep controller and other countermeasures, aiming for CNSA 2.0 compliance by January 2027.

In IoT security, recent cyberattacks have targeted supermarket refrigeration systems across Europe, hitting dozens of stores including Delhaize, Ahold Delhaize, Colruyt, ICA, Coop, and IKEA, by switching evaporators into defrost mode and raising temperatures to 50°C. This demonstrates a critical vulnerability in operational technology and remote control systems, with the initial access method often involving internet-exposed controllers with default credentials or misconfigurations. Additionally, a side-channel information disclosure vulnerability, CVE-2026-20578, has been identified in modems, potentially leading to remote denial of service if a user equipment (UE) connects to a rogue base station controlled by an attacker. Ongoing research, as seen in the upcoming International Conference on Internet of Things Systems Management and Security (ICITSMS) in November 2026, continues to focus on IoT architecture, data security, device management, and privacy considerations, emphasizing the need for robust security protocols for constrained devices and secure firmware updates.
