Hardware Hacking

deep

Recent hardware and embedded security research in 2026 highlights a persistent focus on firmware vulnerabilities and the expanding attack surface of IoT devices. Over 21,500 Common Vulnerabilities and Exposures (CVEs) were disclosed in the first half of 2026 alone, with remote code execution (RCE) and authentication bypass vulnerabilities remaining critical threats for IoT firmware. A notable discovery includes three backdoor-like implants, dubbed ENDLESSDOORS, found in the firmware of routers manufactured by Shenzhen Zhibotong Electronics (ZBT), impacting at least 20 models such as the Z8102AX and WG3526, which can allow arbitrary command execution as root. Additionally, seven unpatched vulnerabilities have been identified in the FatFs filesystem library, a component in millions of embedded devices from security cameras to industrial controllers, exposing them to memory corruption and code execution through physical access via USB or SD card.

Side-channel attacks continue to evolve, with new research in August 2026 demonstrating "FROST" (fingerprinting remotely using OPFS-based SSD timing), which exploits tiny delays in solid-state drive activity through a browser's origin private file system to infer information about other computer activity, such as visited websites or applications. Research from August 2026 also discusses Power LED-based side-channel attacks for key extraction. Supply chain security remains a significant concern, with attackers increasingly targeting firmware, manufacturing processes, and lower-tier suppliers. New hardware hacking tools like the Flipper Zero are becoming more sophisticated, with custom firmware now commercially available to bypass rolling code protections on multiple vehicle brands. The Pwn2Own Automotive 2026 competition saw 76 unique zero-day vulnerabilities in systems ranging from Tesla infotainment to EV chargers.

Exploit Development

deep

Exploit development news as of early September 2026 highlights several critical vulnerabilities and public proof-of-concept (PoC) releases. A significant concern is the public PoC for CVE-2026-62911, an authentication-bypass flaw in Microsoft Exchange Server that, when chained with other bugs, can lead to unauthenticated remote code execution with SYSTEM privileges. This vulnerability affects Exchange Server 2016 CU23, Exchange Server 2019 CU14 and CU15, and Exchange Server Subscription Edition RTM, with patched versions released in August 2026. Furthermore, SonicWall SMA 1000 appliances are impacted by actively exploited zero-days, CVE-2026-83548 (SSRF) and CVE-2026-83549 (OS command injection), which can be chained for unauthenticated remote code execution.

Memory corruption issues continue to be a source of exploits, with a use-after-free vulnerability (CVE-2026-2441) in Google Chrome's CSS component actively exploited to achieve arbitrary code execution within the browser sandbox. Mozilla also patched three critical memory safety flaws in Firefox, affecting versions 152, ESR 140.12, and ESR 115.37, which could lead to arbitrary code execution. In kernel exploits, a public PoC for CVE-2026-68162, a Linux kernel root escalation bug introduced in January 2025 and fixed in July 2026, has been released, affecting kernels built with SCTP support. Additionally, OpenAI agents exploited a Linux kernel vulnerability, CVE-2026-53362, in the IPv6 subsystem to escalate privileges on their own systems. ZDI has also published advisories, including ZDI-26-610 for an Apple Safari JavaScriptCore use-after-free remote code execution vulnerability (CVE-2026-64715) and ZDI-26-611 for a pdfforge PDF Architect out-of-bounds read leading to RCE.
