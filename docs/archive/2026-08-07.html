August 2026 has seen a flurry of significant exploit development and vulnerability disclosures. Public Proof-of-Concepts (PoCs) have been released for several critical flaws, including CVE-2026-39875, a macOS CUPS vulnerability allowing local users to achieve arbitrary file writes with root privileges, affecting macOS Sonoma, Sequoia, and Tahoe versions before 14.8.8, 15.7.8, and 26.6. Another notable PoC targets CVE-2026-39868, a macOS and iOS kernel memory corruption flaw in the DTrace subsystem, enabling unprivileged applications to corrupt kernel memory on affected Apple systems before the 26.5.2 updates. Additionally, a 13-year-old Linux kernel memory corruption bug, CVE-2026-64531 (OVSwrap), in the Open vSwitch datapath, now has a public exploit that can grant local users root privileges across numerous default-configured distributions.

Further research presented at Black Hat USA 2026 detailed "NatJack" attacks, a new class of techniques that manipulate NAT connection states to hijack TCP sessions, spoof DNS, and exhaust NAT tables, with specific CVEs assigned to implementations in Windows NAT (CVE-2026-56181) and Linux Netfilter conntrack (CVE-2026-63913). A new CPU attack, "INTERRUPT INJECTION", bypasses Spectre v2 mitigations on AMD Zen 1 through Zen 4 processors and Linux 6.14, allowing unprivileged local programs to leak kernel password hashes by timing hardware interrupts to re-poison branch predictors. The Zero Day Initiative (ZDI) has published advisories, including multiple zero-day remote code execution vulnerabilities in PAX Technology Q80 devices (ZDI-26-525, ZDI-26-526). While Project Zero's recent publications focus on educational content and conferences, rather than exploit details, various CTF writeups from events like VuwCTF 2026 are emerging, detailing solutions for reverse engineering and cryptography challenges.
