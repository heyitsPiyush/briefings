deep

August 2026 saw significant exploit development news, with Microsoft's Patch Tuesday addressing 421 CVEs, including one exploited zero-day and two publicly disclosed vulnerabilities. The exploited zero-day, CVE-2026-68820, is an elevation of privilege flaw in the Windows Ancillary Function Driver for WinSock (afd.sys) that has been leveraged by threat actors for SYSTEM privileges, with some reports linking it to the Lazarus Group. Additionally, a public proof-of-concept (PoC) for CVE-2026-39875, a macOS CUPS vulnerability, was released, allowing unprivileged local users to perform arbitrary file writes with root privileges.

Other notable developments include the "NatJack" attack class, presented at Black Hat USA 2026, which manipulates NAT connection states to hijack TCP sessions and spoof DNS, affecting both Windows (CVE-2026-56181) and Linux (CVE-2026-63913) implementations. Researchers also unveiled "Ghostjacking" at DEFCON 2026, a technique exploiting AI agents' trusted access to bypass firewall controls by rerouting traffic through an organization's own AI, a "self-exploit" method observed against the Claude Code AI agent. Furthermore, a critical SharePoint authentication bypass, CVE-2026-55040, saw active exploitation after a public PoC release, enabling unauthenticated attackers to impersonate administrators.
