Exploit development in July 2026 saw significant activity, particularly with multiple critical vulnerabilities and public proof-of-concept (PoC) releases. A notable authentication bypass (CVE-2026-16232) in Check Point SmartConsole was actively exploited, allowing unauthenticated remote attackers to gain full administrative privileges; Check Point released patches on July 22, 2026, and Rapid7 subsequently released a PoC. Another critical flaw, "Certighost" (CVE-2026-54121), an Active Directory Certificate Services (AD CS) privilege elevation vulnerability, also received a public PoC release, enabling authenticated attackers to potentially compromise Windows domains. Additionally, Russian threat actors exploited CVE-2026-42897, a cross-site scripting (XSS) vulnerability in Outlook Web Access (OWA), deploying a JavaScript implant called OWAReaper for persistent access.

Memory corruption research and kernel exploits also featured prominently. Six high-severity vulnerabilities in FFmpeg were disclosed, allowing arbitrary memory corruption, denial-of-service, and information disclosure through malicious media files, affecting versions up to 8.1.28. Two Linux kernel zero-days, GhostLock (CVE-2026-43499) and Bad Epoll (CVE-2026-46242), were identified, both granting full root control to local users. Researchers also published a Linux kernel exploit (CVE-2026-53264), a use-after-free race in the network traffic-control subsystem, with AI assistance cited in its discovery and exploit development. Microsoft's July 2026 Patch Tuesday addressed a record 621 CVEs, including two actively exploited zero-days and critical flaws in SharePoint, Windows DHCP Server, and Exchange Server. A critical SQL injection (CVE-2026-60137) and a REST API batch request route confusion (CVE-2026-63030) in WordPress Core could be chained for unauthenticated administrator account creation, with active exploitation observed.
