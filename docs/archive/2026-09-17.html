Exploit Development

deep

Exploit developers have been highly active in September 2026, with several critical vulnerabilities and exploit chains emerging. Notably, a multi-stage exploit chain, dubbed "BlueMoon," actively targeted Google Chrome and Windows, leveraging CVE-2026-85046, a type-confusion bug in Chrome's V8 JavaScript engine, and CVE-2026-87491, a V8 sandbox escape. This chain culminated in a Windows kernel local privilege escalation (LPE) flaw, CVE-2026-85880, found in RtlpCreateServerAcl, affecting Windows 10 versions 1809 through 22H2, Server 2022, and Windows 11 21H2. Additionally, Google patched another actively exploited Chrome V8 zero-day, CVE-2026-87491, described as an out-of-bounds write vulnerability, allowing remote code execution within the browser's sandbox.

Beyond browser and kernel exploits, September also saw the disclosure of other significant vulnerabilities. Cisco warned of an actively exploited, maximum-severity authentication bypass (CVE-2026-76460) in its Identity Services Engine (ISE) API, with a CVSS score of 10.0, allowing unauthenticated remote attackers to gain unauthorized access. Apache Superset also had a public proof-of-concept released for CVE-2026-23980, a SQL injection flaw in versions prior to 6.0.0, enabling authenticated users with read access to trigger error-based SQL injection. Furthermore, Microsoft's September Patch Tuesday addressed a record 974 vulnerabilities, including two exploited zero-days beyond the aforementioned Chrome/Windows chain, such as CVE-2026-81963, an elevation of privilege in the Windows Update Stack, and a new proof-of-concept zero-day exploit for Microsoft Defender dubbed "ShieldCrash" which bypasses a previous fix for CVE-2026-69414.
