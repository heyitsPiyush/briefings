Hardware Hacking

deep

Recent weeks have seen significant disclosures in hardware and embedded security. Notably, a zero-day boot-chain vulnerability was reported in HP ThinPro 8 and 9, allowing physical attackers to bypass Trusted Platform Module (TPM) full-disk encryption and extract LUKS keys due to an incomplete measured-boot policy that omits the Linux kernel and initramfs. Furthermore, a critical SQL injection flaw, CVE-2026-72898, in Metabase's /reset_password endpoint led to a supply chain attack on Trezor, compromising the shipping addresses and personal data of approximately 14,000 customers after attackers gained full administrator control over the database. In IoT security, the Dysphoria botnet has compromised nearly 296,000 IoT devices, primarily for use in distributed denial-of-service attacks.

Fault injection testing has seen advancements with Google Cloud introducing a preview service to test application resilience by injecting faults into cloud resources like Cloud SQL instances and Layer 7 load balancers. On the side-channel attack front, Microsoft's August 2026 Patch Tuesday addressed a TPM 2.0 RSA OAEP Timing Side-Channel Vulnerability, CVE-2026-6727. In RF hacking, a pro-Russian group, Server Killers, claimed responsibility for cyberattacks against Norway in retaliation for its support of Ukraine, though specific RF vectors were not detailed. Additionally, attacks on critical infrastructure included U.S. intelligence agencies warning of an active campaign targeting Siemens S7 Series programmable logic controllers (PLCs) using AI-generated exploitation scripts.

Exploit Development

deep

August 2026 has seen a surge in exploit development news, with several critical vulnerabilities actively exploited or having public proof-of-concept (PoC) code released. Microsoft's August Patch Tuesday addressed 415 vulnerabilities, including one exploited zero-day, CVE-2026-68820, a use-after-free flaw in the Windows Ancillary Function Driver for WinSock (afd.sys) that allows local privilege escalation to SYSTEM privileges. Additionally, ShieldBreak (CVE-2026-69414), an elevation-of-privilege zero-day in the Microsoft Malware Protection Engine (Defender), saw a public PoC release on August 12, 2026, though a patch is not yet available. Linux kernel exploits are also prevalent, with CVE-2026-43494 (PinTheft) chaining a double-free in RDS sockets with iouring for root escalation, and CVE-2026-53361 revealing a use-after-free in the AFUNIX garbage collector allowing container escapes.

Further significant developments include critical memory corruption bugs. Citrix NetScaler ADC and Gateway were affected by CVE-2026-8452, a heap overflow in SAML parsing allowing unauthenticated remote code execution with a single HTTP request. Google Chrome also saw multiple critical memory vulnerabilities patched, including use-after-free and buffer overflow issues like CVE-2026-76034, CVE-2026-76036, and CVE-2026-76017, with some enabling remote code execution outside the browser sandbox. A new class of attack dubbed "TONTOU" was introduced by MIT researchers, which utilizes "interrupt injection" to bypass processor speculative execution defenses like Spectre by dirtying prediction machinery during short instruction gaps. The Zero Day Initiative (ZDI) also published their August 2026 Security Update Review, noting an increase in AI-powered vulnerability discovery impacting bug bounty economics.
