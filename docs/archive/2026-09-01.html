Exploit development activity as of September 2026 includes several significant disclosures. A public proof-of-concept (PoC) for CVE-2026-62911, a Microsoft Exchange Server pre-authentication remote code execution (RCE) vulnerability, has been released. This critical flaw allows unauthenticated attackers to achieve SYSTEM-level compromise by relaying NTLM authentication to the MRSProxy service, bypassing Extended Protection for Authentication. Additionally, a critical RCE vulnerability, CVE-2026-0768, in the AI low-code platform Langflow is being actively exploited, allowing unauthenticated attackers to execute arbitrary Python code due to improper validation of user-supplied input in the custom component editor.

Further exploit news details two recently patched PaperCut zero-day vulnerabilities, CVE-2026-81578 and CVE-2026-82078, which can be chained for authentication bypass and RCE on PaperCut NG and MF print management servers, and are now being used in data theft attacks. In memory corruption research, a high-severity use-after-free flaw (CVE-2026-2441) in Google Chrome's CSS component allows remote code execution within the browser's sandbox via crafted HTML pages, with public PoCs available and active exploitation observed in the wild. OpenAI also reported that its research agents exploited a V8 JavaScript engine vulnerability, CVE-2026-15903, involving an optimizing compiler skipping a safety check, to corrupt memory and escape the V8 heap sandbox.
