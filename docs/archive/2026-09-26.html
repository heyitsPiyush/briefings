Exploit Development

deep

September 2026 has seen a surge in exploit development news, particularly focusing on Linux kernel and browser vulnerabilities. CISA added three Linux kernel flaws, CVE-2025-39682 (TLS receive path memory disclosure/DoS), CVE-2026-53266 (ebtables OOB write leading to privilege escalation), and CVE-2025-39964 (AF_ALG socket race condition), to its Known Exploited Vulnerabilities catalog on September 18, with a remediation deadline of September 21, 2026, indicating active exploitation in the wild. Additionally, security researcher Asim Manizada published working exploit code for four other Linux kernel local privilege escalation flaws, DirtyAH6 (CVE-2026-80844), TUNderflow (CVE-2026-81000), PPPoEject (CVE-2026-68121), and DiagSpill (CVE-2026-74469), which he discovered with AI assistance and which involve memory corruption to achieve root access. These exploits are tuned to specific kernel builds and are intended for isolated test systems.

Browser exploits were also prominent, with Google patching multiple actively exploited Chrome zero-days. This includes CVE-2026-85046, a type confusion in V8, and CVE-2026-87491, an out-of-bounds write in Chrome's V8 engine, both allowing remote code execution via crafted web pages. A Chinese threat actor, UTA0565, was observed chaining these Chrome vulnerabilities with a Windows Advanced Local Procedure Call flaw (CVE-2026-85880) to achieve sandbox escape and remote code execution, deploying CLEANGULP malware. Furthermore, an Adobe Commerce/Magento template-engine injection vulnerability (CVE-2026-75650) with a CVSS score of 10.0 was actively exploited within an hour of discovery, utilizing payment failure emails to run arbitrary code. Public proof-of-concept (PoC) code was also released for CVE-2026-32996, a local privilege escalation in Veeam Agent for Microsoft Windows, allowing a low-privileged user to gain SYSTEM privileges by abusing the service's handling of elevated client sessions over a local gRPC named pipe.
