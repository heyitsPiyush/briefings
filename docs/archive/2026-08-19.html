Exploit development news for August 2026 highlights several critical vulnerabilities and exploit releases. Microsoft's August 2026 Patch Tuesday addressed 415 vulnerabilities, including one actively exploited zero-day, CVE-2026-68820, an elevation of privilege flaw in the Windows Ancillary Function Driver for WinSock (afd.sys). This use-after-free bug allows a local attacker to gain SYSTEM privileges and has been exploited in the wild by groups like Lazarus, who deployed the FudModule kernel-mode rootkit. Another significant Windows vulnerability, CVE-2026-47301, a critical remote code execution flaw in Microsoft Configuration Manager (SCCM), also saw a public proof-of-concept (PoC) released, enabling low-privileged domain users to achieve SYSTEM access on Primary Site Servers.

In browser and kernel exploitation, multiple vulnerabilities were identified in Google Chrome, with CVE-2026-76034 and CVE-2026-76036 being critical remote code execution flaws affecting WebGPU and Dawn respectively, allowing attackers to execute arbitrary code outside the sandbox via crafted HTML pages. Additionally, a new class of zero-click exploits dubbed "PleaseFix" was demonstrated at Black Hat USA 2026, targeting AI browsers like Claude in Chrome and Gemini in Chrome by exploiting how AI agents process untrusted content to hijack them and exfiltrate sensitive data. Linux kernel also saw a critical race condition, CVE-2026-68138 (RtabRace), in its traffic-control networking subsystem, which allows unprivileged local users to corrupt kernel memory, with a public PoC available that achieved root on Ubuntu 22.04 and could cause kernel panics on CloudLinux. CVE-2026-68288 and CVE-2026-68089 were also disclosed as information disclosure flaws in the Linux kernel's drop_monitor and IIO core debugfs components, respectively, leaking uninitialized padding bytes or data to user space.
